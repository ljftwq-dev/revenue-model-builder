# 智谱（02513.HK）2026H1 收入预测复盘：ARR 锚点法

> **预测时点**：2026-08-30（中期业绩披露前一日）｜ **对答案**：2026-08-31 港交所《截至2026年6月30日止六个月的中期业绩公告》
>
> 一个"事前预测 → 事后对答案"的完整案例：只用手报披露前的公开信息预测 2026H1 收入，再和实际值比对，检验 ARR 锚点法在爆发期公司的适用性。

## 1. 任务设定

假装回到 2026-08-30：智谱明天盘后才发上市以来第一份中期业绩。你手里只有年报、招股书和媒体披露的 ARR 里程碑，没有 8/31 之后的任何信息。预测 2026H1 总收入，并给出云端占比、毛利率、净亏损的区间判断。

## 2. 预测时点的公开信息集（详见 `data/pre_report_info.json`）

| 信息 | 数值 | 来源 |
|---|---|---|
| 2025H1 收入 | 1.909 亿元 | 招股书（经审计） |
| 2025 全年收入 | 7.24 亿元（+132%） | 2025 年度业绩（2026-03-31） |
| MaaS ARR（2026-03） | 17 亿元，12 个月提升 60 倍 | 2025 年报口径，中金在线转引 |
| ARR（2026-07） | $10 亿（≈67.2 亿元），前 7 个月增 15 倍 | 《智能涌现》2026-08 报道 |
| Coding Plan 提价 | 中国区 +30% 起、海外 +100%（2/12）；API 年内累计 +80%（3 月） | 公司调价函 / 财联社 / 东方财富 |

注：1 月 ARR 为隐含锚点 = 7 月 ARR ÷ 15 = 4.48 亿元；汇率按公告口径 6.72。

## 3. 三种预测方法

| 方法 | 思路 | 关键公式 |
|---|---|---|
| **M1 朴素同比** | 把 2025 年度增速套在 H1 上 | 2026H1 = 2025H1 × (1 + 132%) |
| **M2 单锚点指数** | 1月/7月两个 ARR 锚点，几何内插月度 ARR，月收入 = ARR/12 | g = 15^(1/6)，H1 = Σ ARR_i·g^i / 12 |
| **M3 双锚点内插** | 1月/3月/7月三个锚点，分段几何内插（前快后慢） | f₁=(17/4.48)^½，f₂=(67.2/17)^¼ |
| **M3' 转化率修正** | M3 × ARR→确认收入转化率 0.85 | 事后校准值，样本外建议用 0.80–0.90 区间 |

## 4. 结果：预测 vs 实际（实际 2026H1 收入 = 9.54 亿元，+399.7%）

| 方法 | 预测（亿元） | 误差 | 点评 |
|---|---|---|---|
| M1 朴素同比 | 4.43 | **-53.6%** | 爆发期朴素外推严重失效 |
| M2 单锚点指数 | 9.16 | **-4.0%** | 最准，但含运气成分（见教训④） |
| M3 双锚点内插 | 11.31 | +18.6% | ARR 口径高于确认收入，系统性高估 |
| M3' ×0.85 修正 | 9.62 | **+0.8%** | 校准转化率后几乎命中 |

## 6. 复盘教训

1. **爆发期朴素外推失效**（-54%）：H1 实际增速 400% 远超上年年度增速 132%，历史增速不是增速的上限。
2. **ARR 是爆发期最强领先指标**：官方/媒体披露的 ARR 里程碑足以把收入预测误差压到个位数，比任何财务外推都灵。
3. **ARR ≠ 确认收入**：实测转化率 ≈ 0.84（折扣、赠送 token、试用、订阅 vs 按量口径混合、确认滞后），双锚点法必须打折。
4. **增长路径非单指数**：Jan→Mar 月环比 ≈1.95x 快于 Mar→Jul ≈1.41x（前快后慢）；M2 的"走运"来自低估中年段与 ARR 口径高估的部分对冲。
5. **提价未显式建模**：2 月 Coding Plan +30% 的价格驱动应进入量价分解（收入 = 付费 token × 单价），是本案例的改进方向。
